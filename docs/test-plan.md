# Тест-план: сайт ЛМШ «Альтернатива»

## Объект тестирования

Статический сайт https://altlmsh.site: 14 страниц на HTML, CSS и JavaScript, без бэкенда. Интерактивные части: мобильное меню, фильтры на странице «Люди», навигация по годам на странице «История», просмотр фото крупно.

## Цели

1. Каждая страница открывается без ошибок, все ссылки и картинки рабочие.
2. Правила из README сайта соблюдаются: одинаковое меню, `sitemap.xml`, мета-теги для поисковиков и соцсетей, одинаковые номера версий стилей.
3. Интерактивные части работают с мышью, клавиатурой и на телефоне.

## Что не тестируем

- Скорость загрузки и нагрузку: это статика на хостинге.
- Сборку `build.mjs` и выкладку на Timeweb: их проверяет GitHub Actions самого сайта.
- Содержание текстов.

## Подход

| Уровень | Как | Где |
|---|---|---|
| Смоук и регрессия | автотесты Playwright + pytest | `tests/` |
| Проверки по README сайта | автотесты, параметризованные по `sitemap.xml` | `tests/test_pages.py`, `tests/test_navigation.py` |
| Функциональные | тест-кейсы → автотесты | [`test-cases.md`](test-cases.md), `tests/test_features.py` |
| Исследовательское тестирование | ручное, по чек-листу | [`checklist.md`](checklist.md) |

Техники тест-дизайна: классы эквивалентности и граничные значения (ширина экрана 320/375/768/1280 px, значения фильтров: пустое, существующее, год без смены, несуществующее), попарное сочетание фильтров «год × кафедра», негативные сценарии (испорченная ссылка с фильтром).

## Окружение

- Chromium через Playwright, разрешения 1280×800 (десктоп) и 320, 375, 768 px (телефоны и планшет).
- Прогон: на каждый push, по расписанию каждый день против живого сайта и вручную с любым адресом (`workflow_dispatch`).

## Критерии

- Начало: сайт открывается, `sitemap.xml` доступен.
- Окончание: все тесты зелёные, а найденные дефекты оформлены в [`bug-reports.md`](bug-reports.md) и отмечены в коде `xfail(strict=True)`. Как только баг исправят, такой тест упадёт с XPASS и напомнит снять отметку.
