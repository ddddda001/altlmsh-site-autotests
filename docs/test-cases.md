# Тест-кейсы

Каждому кейсу соответствует автотест, его имя указано в скобках.

### TC-01. Фильтр по году на странице «Люди» (`test_people_year_filter`)

**Предусловие:** открыта `/people.html`, фильтры не выбраны.

| # | Шаг | Ожидаемый результат |
|---|---|---|
| 1 | Нажать кнопку первого года в ряду «Год» | Кнопка становится нажатой (`aria-pressed="true"`) |
| 2 | Посмотреть на карточки | Видны только люди, у которых этот год есть в подписи (в том числе внутри диапазона «2016–2019») |
| 3 | Посмотреть на строку статуса | «Смена ГОД: показано N из M», N равно числу видимых карточек |
| 4 | Посмотреть на адрес страницы | В адресе появился `?year=ГОД` |

### TC-02. Фильтр открывается по ссылке (`test_people_filter_from_url`)

| # | Шаг | Ожидаемый результат |
|---|---|---|
| 1 | Открыть `/people.html?dept=Физмат` | Нажата кнопка «Физмат», в статусе написано «Физмат» |
| 2 | Посмотреть на карточки | У каждой видимой карточки кафедра «Физмат» |

### TC-03. Сброс фильтра (`test_people_reset_with_all`)

| # | Шаг | Ожидаемый результат |
|---|---|---|
| 1 | Открыть `/people.html?dept=Физмат` | Показаны не все люди |
| 2 | Нажать «Все» в ряду «Кафедра» | Показаны все, `dept` пропал из адреса |

### TC-04. Год без смены (`test_people_no_shift_year_shows_message`)

Класс эквивалентности «год в допустимом диапазоне, но смены не было».

| # | Шаг | Ожидаемый результат |
|---|---|---|
| 1 | Открыть `/people.html?year=2020` | Карточек нет, статус «Никого не нашли — попробуй другой год или кафедру» |

### TC-05. Несуществующее значение фильтра (`test_people_unknown_filter_value`)

Негативный сценарий: старая или испорченная ссылка.

| # | Шаг | Ожидаемый результат |
|---|---|---|
| 1 | Открыть `/people.html?year=abc` | Сообщение «Никого не нашли» |
| 2 | Посмотреть на кнопки фильтров | Видно, что действует фильтр по году, и его можно сбросить. **Фактически:** ни одна кнопка года не нажата → BUG-002 |

### TC-06. Мобильное меню (`test_mobile_menu_opens_and_closes`)

**Предусловие:** ширина окна 375 px, открыта главная.

| # | Шаг | Ожидаемый результат |
|---|---|---|
| 1 | Посмотреть на шапку | Видна кнопка «Меню», `aria-expanded="false"`, список разделов скрыт |
| 2 | Нажать «Меню» | Список открылся, кнопка называется «Закрыть», `aria-expanded="true"` |
| 3 | Нажать «Закрыть» | Список скрылся, кнопка снова «Меню», `aria-expanded="false"` |

### TC-07. Просмотр фото с клавиатуры (`test_photo_keyboard_access`)

| # | Шаг | Ожидаемый результат |
|---|---|---|
| 1 | На `/history.html` перейти Tab'ом на первое фото | Фото в фокусе |
| 2 | Нажать Enter | Открылось окно с этим фото |
| 3 | Нажать Esc | Окно закрылось, фокус вернулся на фото |

### TC-08. Ширина страниц на телефонах (`test_no_horizontal_scroll_on_phones`)

Граничные значения ширины: 320 (самые узкие телефоны), 375 (типичный), 768 (планшет).

| # | Шаг | Ожидаемый результат |
|---|---|---|
| 1 | Для каждой страницы из `sitemap.xml` открыть её на ширине 320/375/768 | Ширина документа не больше ширины окна. **Фактически:** на 320 px `it.html` шире на 20 px → BUG-001 |
